# AutoManager4Events

Trabajo de Fin de Grado centrado en la automatización inteligente de procesos mediante workflows, integración de IA y gestión automatizada de eventos y recursos.

---

# Objetivos del proyecto

El objetivo principal del proyecto es diseñar un sistema modular capaz de automatizar distintos procesos organizativos y administrativos utilizando workflows y herramientas de automatización.

---

# Casos de uso implementados

## 1. Gestión de catering

Automatización de procesos relacionados con:

- Gestión de eventos
- Organización de catering
- Procesamiento de solicitudes
- Automatización de flujos operativos

Ubicación:

```text
workflows/catering/
```

---

## 2. Gestión de guardias hospitalarias

Automatización de:

- Envío de disponibilidad
- Lectura automática de respuestas
- Procesamiento de datos de guardias

Ubicación:

```text
workflows/guardias/
```

---

## 3. Gestión de proyectos software

Automatización orientada a:

- Gestión de tareas
- Seguimiento de proyectos
- Automatización de procesos de desarrollo

Ubicación:

```text
workflows/software-project-management/
```
